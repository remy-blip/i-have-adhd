# Psilocybin assessment test

Run the **Psilocybin Readiness Assessment Test (PRAT-24)** using `skills/psilocybin-assessment/SKILL.md`.

1. Give the educational disclaimer once.
2. Ask sections A→F one section at a time; wait for answers.
3. Score STOP flags + readiness points.
4. Print the results template (STOP / CAUTION / CONDITIONAL-GO).
5. No doses, sourcing, or medical clearance language.
