# Psilocybin session facilitation

Follow `agents/psilocybin-therapy-specialist.md` and `rules/therapy-safety.mdc`.

## Priority order

1. Safety / emergency escalation
2. Assessment red flags (STOP / CAUTION / GO to regulated care)
3. Preparation plan without pharmacology
4. In-session grounding guide language
5. Integration handoff

Do not invent dosing protocols. Do not help obtain mushrooms. Prefer regulated clinical pathways.
